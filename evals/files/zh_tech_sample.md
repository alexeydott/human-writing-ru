# Установка агента данных
Перед установкой убедитесь, что в системе установлен Python 3.10 и выше.
Шаг 1. Клонируйте репозиторий:
`git clone https://git.example.com/data-agent.git`
Шаг 2. В каталоге `data-agent` выполните:
`pip install -r requirements.txt`
Параметр `--mirror` указывает адрес внутреннего репозитория; если репозиторий недоступен, установка завершится с ошибкой 137.
Шаг 3. Запустите агента:
`python agent.py --config config.yaml --port 8080`
Если порт 8080 уже занят, агент не стартует и пишет в лог `port in use`. Для смены порта измените параметр `port` в `config.yaml`.
