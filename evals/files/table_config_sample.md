Конфигурация агента задаётся в файле `config.yaml`. Перед запуском сверьте значения с таблицей:

| параметр | значение | назначение |
|----------|----------|------------|
| `host` | `0.0.0.0` | адрес прослушивания |
| `port` | `8080` | порт HTTP-интерфейса |
| `workers` | `4` | число рабочих процессов |
| `log_level` | `info` | уровень детализации логов |

Если значение `workers` больше числа ядер CPU, агент выдаст предупреждение, но продолжит работу. Параметр `log_level` можно менять без перезапуска.
