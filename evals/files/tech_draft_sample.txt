Нужно написать инструкцию по установке монитора окружения. Система — Windows 11, версия приложения 3.2. Сначала проверяем python (python --version), должно быть 3.10 или выше. Потом ставим зависимости: pip install -r requirements.txt. Дальше копируем config.example.yml в config.yml и правим host, port, interval. Запуск: python monitor.py --config config.yml. Если порт занят, приложение пишет в лог и не стартует. Логи лежат в logs/monitor.log. Остановка — по Ctrl+C, состояние пишется в state.json.
