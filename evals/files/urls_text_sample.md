Чтобы настроить резервное копирование, сделайте три шага.
Сначала загрузите утилиту с официальной страницы: https://backup.example.org/download
Затем проверьте статус вашего аккаунта — он должен быть активен: https://account.example.org/status
И только потом откройте руководство по настройке: https://docs.example.org/backup/ru
Если после третьего шага окно настройки не открылось, перезапустите утилиту и повторите шаги по порядку — без перестановки.
