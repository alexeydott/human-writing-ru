# Data directory

Пакет намеренно не содержит внешние корпусные тексты.

Храните локальные исследовательские выборки вне репозитория или в игнорируемом каталоге и сохраняйте для каждого документа метаданные: source, license/terms, date, genre/channel, origin, audience (если известно законно и этично), split и transformation history.

Не используйте персональные данные из социальных корпусов для генерации профилей конкретных людей.
