# Проход 5. Диагностика по классам ошибок и false positives

## Наблюдение

Агрегированная метрика может скрывать ухудшение по отдельному правилу. Для русского GEC это показано в работе BEA 2026: улучшение общей метрики сопровождалось резким ухудшением отдельной пунктуационной категории. LORuGEC ранее был создан именно как диагностический rule-annotated benchmark сложных русских правил.

Источники:
- https://aclanthology.org/2026.bea-1.32/
- https://aclanthology.org/2025.bea-1.38/

## Следствие для Skill

1. Не принимать общий pass rate за достаточное доказательство улучшения.
2. Хранить eval-результаты по dimensions и классам риска.
3. Иметь negative-control набор нормативных конструкций, которые Skill не должен «лечить».
4. Отдельно проверять сохранение смысла и минимальность редактуры.
5. Для грамматической коррекции использовать rule-level диагностику; стилевой линтер не подменяет GEC.
